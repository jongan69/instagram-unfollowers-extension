Features

Everything you need to clean up your following list

Built with privacy and safety in mind. All operations run client-side through Instagram's own API — nothing goes through a third-party server.

🔍

Smart Scanning

Iterates through your entire following list using Instagram's GraphQL API with configurable delays to avoid rate limits.

👥

Non-Follower Detection

Instantly identifies who doesn't follow you back. Filter by verified, private, or users without a profile picture.

⚡

Batch Unfollow

Select multiple users at once with quick-select groups (verified, private, no pic) and unfollow them in bulk.

★

Whitelist

Mark accounts to keep following. Export and import whitelists as JSON to share across devices or back up.

🛡️

Rate Limit Protection

Customizable delays between scans and unfollows. Cooldown periods after every 5 actions to mimic human behavior.

🔒

100% Private

No servers, no analytics, no tracking. Your following list, whitelist, and settings never leave your browser.

How it works

Three simple steps

The extension works entirely within your browser. It communicates directly with Instagram's official API — no middleman, no external services.

1

Open Instagram and click the extension icon

Log into Instagram in Chrome, then click the Unfollowers icon in your toolbar. The app opens in its own window.

2

Run a scan

Click "Start Scan" to fetch your full following list. The extension pages through Instagram's GraphQL API with built-in delays to stay under rate limits.

3

Review and unfollow

Filter the results, select the accounts you want to unfollow, and click "Unfollow." The extension processes them with configurable delays to keep your account safe.

Installation

Get started in under a minute

Load the extension in Chrome Developer Mode. No account needed, no sign-up required.

Terminal 
# Clone the repository
git clone https://github.com/jongan69/instagram-unfollowers-extension.git
cd instagram-unfollowers-extension

# Install and build
npm install
npm run build

# Then load the dist/ folder in chrome://extensions

Or download the pre-built release: Grab the latest .zip from the Releases page, unzip, and load the folder as an unpacked extension in chrome://extensions with Developer mode enabled.

Privacy

Your data stays on your machine

This extension is designed to be fully client-side. Here's what that means in practice:

🏠

Local Storage Only

Settings, results, and whitelist are stored in Chrome's local storage — nowhere else.

🚫

No External Servers

The extension only talks to Instagram's API. It never connects to any third-party server.

👁️

No Analytics

Zero tracking, zero telemetry, zero data collection. What you do is your business.

📖

Open Source

Every line of code is on GitHub. You can audit it, fork it, or build it yourself.
